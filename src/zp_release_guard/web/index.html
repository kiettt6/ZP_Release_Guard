  • Đính kèm ảnh, PDF hoặc DOCX — tự động OCR rồi phân tích

  • Dùng Copy hoặc Tải .md để dán báo cáo vào Jira / Merge Request
  • Hỗ trợ tiếng Việt và English — tự nhận diện
